**404Brain** — IDE desktop focada em IA, baseada no [VS Code](https://github.com/microsoft/vscode).

Agentes no seu código. Checkpoints e diffs ao vivo. Qualquer modelo ou host local. As mensagens vão direto aos provedores — seus dados ficam com você.

## Recursos

- Agentes de IA sobre arquivos reais do projeto
- Checkpoints e diffs visuais conforme o código chega
- Seus próprios modelos / hosts locais (compatíveis com OpenAI, Ollama e mais)
- Código-fonte completo do app desktop neste repositório
