**404Brain** — IDE bureau axé IA, basé sur [VS Code](https://github.com/microsoft/vscode).

Des agents sur votre code. Points de contrôle et diffs en direct. N’importe quel modèle ou hôte local. Les messages vont directement chez vos fournisseurs — vos données restent les vôtres.

## Fonctionnalités

- Agents IA sur les vrais fichiers du projet
- Points de contrôle et diffs visuels pendant le streaming du code
- Vos propres modèles / hôtes locaux (compatibles OpenAI, Ollama, etc.)
- Code source complet de l’app bureau dans ce dépôt
