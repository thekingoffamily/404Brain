**404Brain** — AI-first десктоп IDE на базі [VS Code](https://github.com/microsoft/vscode).

Агенти над вашим кодом. Чекпоінти та живі дифи. Будь-які моделі чи локальні хости. Повідомлення йдуть просто до провайдерів — ваші дані лишаються з вами.

## Можливості

- AI-агенти над реальними файлами проєкту
- Чекпоінти та візуальні дифи під час стрімінгу коду
- Власні моделі / локальні хости (OpenAI-compatible, Ollama тощо)
- Повний вихідний код десктоп-застосунку в цьому репозиторії
