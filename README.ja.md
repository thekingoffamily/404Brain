**404Brain** — [VS Code](https://github.com/microsoft/vscode) ベースの AI ファーストなデスクトップ IDE。

コードベース上の AI エージェント。チェックポイントとライブ diff。任意のモデルやローカルホスト。メッセージはプロバイダーへ直接 — データはあなたのもとに。

## 機能

- 実プロジェクトファイル上の AI エージェント
- コードストリーム中のチェックポイントと視覚的 diff
- 自分のモデル / ローカルホスト（OpenAI 互換、Ollama など）
- このリポジトリにデスクトップアプリの全ソース
