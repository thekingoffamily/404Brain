# 404Brain — документация (docs)

Все заметки проекта хранятся в Markdown, чтобы новый агент/человек мог быстро понять проект.

## Оглавление

- [Arхитектура Brain](architecture.md) — карта файлов, ключевые сервисы, потоки данных.
- [Каталог тулзов и умений](tools-and-skills.md) — полный список builtin-тулзов, комбо-паттерны (умения) и регламенты.
- [Сборка и запуск](build-and-run.md) — как собрать, как развернуть проект на новом ПК.

## Правила

1. Ключи/токены/секреты никогда не пишутся в файлы, комментарии, логи, коммиты и релизы. Только плейсхолдеры.
2. Любая важная механика и найденный факт (форматы данных, работа чужого софта, баги, рецепты) должны быть
   зафиксированы здесь или в AGENTS.md — не держим их только в голове/контексте.
3. После каждой заметной сессии обновляется раздел «История работ» в AGENTS.md.
