**404Brain** — [VS Code](https://github.com/microsoft/vscode) 기반 AI 우선 데스크톱 IDE.

코드베이스 위 AI 에이전트. 체크포인트와 실시간 diff. 어떤 모델이나 로컬 호스트든. 메시지는 제공자에게 바로 — 데이터는 당신 것.

## 기능

- 실제 프로젝트 파일 위 AI 에이전트
- 코드 스트리밍 중 체크포인트와 시각적 diff
- 자체 모델 / 로컬 호스트 (OpenAI 호환, Ollama 등)
- 이 저장소에 데스크톱 앱 전체 소스
